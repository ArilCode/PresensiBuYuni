Tentang web ini

Web ini dipakai untuk melihat presensi (absensi) sholat siswa. Data diinput oleh guru/pengelola melalui web terpisah, lalu ditampilkan di sini.

Guru pembimbing:

Cara menggunakan

  1. Buka menu Beranda.
  2. Pilih bulan dan tahun. Pilih tanggal jika ingin satu hari saja.
  3. Tekan tombol Tampilkan.
  4. Daftar presensi muncul, nama diurutkan sesuai abjad.
  5. Arti status: Hadir Sakit Izin Alfa

Data tidak tampil sebelum kamu memilih bulan & tahun — ini disengaja demi menjaga privasi.

Laporkan masalah

Menemukan data yang salah atau web yang error? Kirim laporan lewat email atau media sosial di bawah. Sertakan tanggal yang dilihat dan foto layar bila ada.
